1. Installing and getting started

What it runs on

Android 7.0 or later, on a 64-bit phone or tablet, which every phone and tablet of the last several years is. MyEmail is not in the Play Store: it is installed once from its download page, and from then on it updates itself (see Updates in section 13).

Installing

  1. On the phone or tablet, open github.com/rdvir10/MyEmail/releases/latest in the browser.
  2. Under Assets, tap myemail-arm64.apk. If the browser warns that this kind of file can harm the device, download it anyway.
  3. Open the download, from the download notification or from Files → Downloads.
  4. Android says the browser is not allowed to install unknown apps: tap Settings, turn on Allow from this source, go back, and tap Install.
  5. If Google Play Protect offers to scan the app first, let it, then tap Install.
  6. Open MyEmail and allow notifications when it asks. Without them, nothing announces new mail.

It then asks for an account, or offers Restore from a backup if this device is replacing another (see Moving to a new device below).

Installing a newer download over MyEmail keeps every account and every message, because every version is signed the same way.

Adding an account

Settings → Accounts → Add, or the app asks on first run.

Gmail

  1. Tap Gmail, then Sign in with Google.
  2. Choose the account in the browser that opens.
  3. Google says Google hasn't verified this app: tap Advanced, then Go to MyEmail (unsafe). The wording is Google's, because MyEmail is not in the Play Store.
  4. Tick every permission (mail, calendar, Meet) and tap Continue. MyEmail comes back with the account added.

An app password still works instead of Google sign-in, but only Google sign-in lets a meeting made in MyEmail go on the Google calendar.

Outlook.com, Microsoft 365, or a work account

  1. Tap Outlook and sign in on Microsoft's page. If the account uses the Authenticator app, approve the sign-in there and come back: the sign-in waits for you.
  2. A work account may say the app needs an administrator's approval: tap Request approval, and sign in again once it has been approved. Making meetings may need a second approval the same way; the New meeting screen offers it when it does.

No Microsoft password is stored here. Passwords and tokens go into the Android Keystore. They are never written to a file, and they are not in the settings backup unless you ask for that and set a passphrase.

Each account's page, Settings → Accounts → the account, sets the name it is shown under and its colour, which is also the colour of its notifications.

A shared mailbox (info@, sales@) that someone has given your Microsoft account access to:

  1. Settings → Accounts → Add a shared mailbox (under the accounts).
  2. Under Shared with, choose the Microsoft account it was shared with.
  3. Type the shared mailbox's address, and a name for the folder list.
  4. Tap Add. The first time, it may say Not allowed yet: tap Allow and sign in to that Microsoft account again; a work account's organisation may have to approve it first.

It is then an account of its own: its folders in the tree, its mail announced, and it can be chosen in From. Mail from it goes out as the shared mailbox if you have been given Send As, or on its behalf with Send on Behalf, and is kept in its own Sent Items. It has no sign-in of its own: it opens through the account it is shared with, goes when that account is removed, and its invitations are answered by mail. Its automatic replies and rules are not changed here.

Moving to a new device

  1. On the old device: Settings → Backup → Save to a file, tick Include sign-in details, and choose a passphrase.
  2. Send the file to the new device: share it, or put it in OneDrive.
  3. On the new device: install MyEmail as above, then tap Restore from a backup on its first screen (or Settings → Backup → Restore from a file later), pick the file, and give the passphrase.

The accounts arrive signed in, with the folder tree's shape, favourites, hidden folders, Quick Steps, signatures, swipe actions, sort and trusted senders. Each device keeps its own mail and settings from then on; restoring the same backup on both is the quick way to set a second one up.

Removing an account

Settings → Accounts → Remove. It says what goes with it — the cached mail for that account, and any shared mailbox reached through it — and asks before doing it.

2. What is on screen

Phone

  • Top bar: the folder you are in with whose it is under it (the account's address, or All accounts for the unified Inbox), how many are unread, the ☰ drawer for folders, 🔍 for search and ⋮ for view and sort.
  • The list, one message per row.
  • ✏️ button, bottom right, for a new message.
  • Tapping a message opens it on its own screen. Back returns to the list.

Tablet, upright

Folders on the left, the list beside them. A message opens on its own screen, or below the list if you set the reading pane to Below.

Tablet, sideways

Folders, list and the open message, all at once, under the command ribbon: Sync, New email, Delete, Reply, Reply all, Forward, Quick Steps, Move, Read, Read aloud, Calendar, Pane, Search, Settings.

  • Drag the lines between the panes to resize them; the sizes are remembered.
  • The ⇤ button beside the folder name hides the folder pane and brings it back. Beside the name: whose folder it is, how many are unread, and 🔍 for search.
  • Pane in the ribbon moves the message pane: right, below, off.

Coming back to the app

Put the app away (Home, Recents, or another app) and it comes back to the mail, not to wherever you left it:

  • Settings, an open message, menus and the folder drawer close.
  • A message you were writing goes into Drafts and closes. If it cannot be saved, offline say, it stays open instead. Come back before the save has finished and it stays open too, with anything you type from then on.
  • Search is put away, ticked messages are unticked, and the list is back at its newest.
  • You land on the Inbox: the one you were in, or your account's Inbox if you were in another of its folders. A home-screen widget opens its own folder, and a notification opens its message.

Some things stay, because leaving is part of doing them: a sign-in (approve it in the Authenticator app, or make an app password in the browser), an account you have changed but not saved, and a new meeting with anything typed in it, or a time, All day or From changed. Picking a file, opening an attachment or a link, printing, and the screen turning off do not count as putting the app away.

3. Reading mail

The list

On the phone each row starts with who it is from, name and address: Crystal R <crystalr@hadco-metal.com>, with the subject on the line under it. On the tablet the sender's name and the subject share the first line, as in Outlook, with the start of the message under them; where the list is too narrow for both, the row keeps two lines. A ↩ in front means you replied to it, a → that you forwarded it — from this app or any other. A closed conversation shows the mark of the message whose sender heads it.

Read and unread rows sit on the same white, as in Outlook. An unread row has its first line in bold, a blue dot and a blue time. A flagged row is pale yellow, as in Outlook. Every row ends with the message's size, for Gmail and Microsoft alike, written the way Outlook's Size column writes it: whole kilobytes, and whole megabytes from 1 MB (130 KB, 2 MB). For Microsoft mail, Outlook on a PC counts its own copy of the message, so now and then the two can be a KB or so apart. A paperclip before the size means an attachment. The number in a pill (2) is a conversation of that many messages.

Attachments on the row. Under a message with files, their names sit in small chips, as in new Outlook: the first three, then how many more (+2). Tap a chip and that file opens in its usual app, without opening the message. A closed conversation shows the files of all its messages, newest first. Pictures the message only shows in its text are not counted, and neither is an invitation's own calendar file. The chips come with a list that has a preview line, so not in Compact, and Settings → View → Attachments on the row puts them away. On a Microsoft account the names come a moment after the row: Microsoft says only that a message has files, and the app asks what they are called. Mail cached before 2.91.0 gets its names over the next few syncs.

Bars divide the list by date: Today and Yesterday with their dates, each earlier day this week by its date, then Last Week, Two Weeks Ago, Three Weeks Ago, Earlier this Month, Last Month and Older. Weeks start on Sunday, as in Outlook.

Tap a bar to fold its messages away; the arrow at its left turns to show it is closed, and the bar shows how many messages are under it and how many of those are unread. Tap it again to open it. Long-press a bar (or right-click it) for Collapse or Expand, Select all or Unselect all, and Mark all as read or unread for everything under it. Unselect all unticks that group, and once nothing is ticked the tick boxes go away. Closed bars open again when you leave the app. With the bottom bar closed, older mail waits for a tap on Load older messages instead of loading by itself.

  • A flagged message's row is pale yellow (a dim amber in dark mode), and a conversation is yellow while anything in it is flagged. There is no flag on the row itself: flag or unflag with the flag button above the open message, a long press on the row, or a swipe set to Flag. A flag with a day says so beside the time: Due today, Due tomorrow, Due Fri 30 Oct, or Overdue in red (see Follow up).
  • Times are written the way your phone's clock is set, 8:14 PM or 20:14.
  • In Sent and Drafts a row says who the message went to instead of who it is from, which is always you there: To: Crystal R <crystalr@hadco-metal.com> for one person, the names for more, as Outlook's Sent Items does.

All, Unread and Filter

Over the list, as in Outlook: All, Unread, and Filter ▾, whose menu has Flagged, Has attachments and To me (you are on the To line, not only copied). The list shows only what the filter keeps, and asks the server for the rest, so an unread or flagged message from months ago is found as well as this morning's; a small spinner at the end of the bar says the server has not answered yet. All shows everything again, and so does choosing the filter that is on a second time.

A message you open under Unread stays where it is while it is open, read or not, so it does not vanish from under you. The filter goes back to All when you put the app away, as a search does. While a filter is on, the list does not page further: what the server holds for it has been fetched already.

Pinned

Pin to top, in a message's ⋮ menu or right-click menu, or on a thread's right-click menu, keeps it at the top of its folder under a Pinned bar, whatever the order below. Unpin in the same places lets it go. Pins are kept on this device: Outlook on the PC has its own, and a pinned message moved to another folder leaves its pin behind.

Conditional formatting

Settings → View → Conditional formatting colours rows. Add rule, then choose what it matches: From contains (a name or address, or part of one, such as hadco.com), Subject contains, or Sent only to me (you alone on the To line, nobody copied); then a colour, and Bold if you like. A matching row has its sender and subject drawn that way, in every list and in search. The first rule a message matches is the one it gets, so Move up the one that matters most. Rules are in the settings backup.

  • Folders show unread/total, so 14/2310 is fourteen unread of two thousand three hundred and ten.
  • Scroll to the bottom and the next fifty load by themselves.
  • A folder always opens at its newest mail, newest by when it arrived.
  • Pull down to check for new mail. The spinner stays until the folder has been checked with the server; if it could not be, the message says which account and why.
  • A folder that cannot be loaded at all, offline with nothing on the phone yet, says so with Try again, and tries again by itself each minute while it is on screen.

Conversations

Off unless you turn them on (⋮ → Conversations). On, a thread is one row; tap it to open the thread, tap again to close. Everything you can do to a message — swipe, menu, tick — a conversation row does to the whole thread, and says how many that is. On a Microsoft account the threads are the ones Outlook shows, since Exchange keeps a conversation on every message; on Gmail a thread is what the reply headers say, and the subject where they say nothing. Messages in different accounts are never one conversation: a Gmail reply to a work message is its own row in All inboxes, so Archive or Move on a thread only ever touches one mailbox. Mark all as read and Flag all on a thread try every message and say which could not be changed.

An open thread also shows your replies from Sent, among its messages by date, each with the name of the folder it is in, as Outlook's Show Messages from Other Folders does. They open like any message, but nothing done to the thread reaches them: deleting a thread from the Inbox leaves what you sent in Sent. A message with only your reply beside it becomes a thread of two, so the reply can be seen. Sent is checked for new replies about every ten minutes while conversations are on.

The message

Reply, Reply all, Forward, Read/Unread, Move, Delete and ⋮ are along the top. Move asks which folder, the same as the ribbon's: the folders you moved to lately at the top, each with where it lives, then the whole tree, drawn as the folder pane draws it and open where the pane has it open — the arrow beside a folder opens or closes what is under it. The folder the message is in now is there, greyed, marked Here now; so is a parent no message can go into, so its folders keep their place. Typing in Search folders turns it into a list of the matches, with their paths. The buttons above a message are as many as fit: the ways of answering, Read, Move, Delete and ⋮ always, then Not junk (in Junk), Archive, the flag, Full screen and the meeting button as there is room. On a phone that is Archive; the flag and Full screen are in the ⋮ menu.

With more than one account, Move lists every mailbox under its own heading, as the folder pane does. The mailbox the message is in starts open; tap another mailbox's heading to open it. Search and the recent folders cover every mailbox, and a folder in another mailbox has the mailbox's name in front of its path (Gmail › Receipts). You can also drag a message onto another mailbox's folder in the pane, and move messages from several accounts together, ticked in All inboxes.

No mail server can move a message to a different account, so the app copies it there and then deletes it from the mailbox it came from. The copy keeps its read and flag state and its original date. The original goes to that mailbox's Trash, and Undo puts it back and takes the copy out of the folder it went to. A copy in a Microsoft mailbox is rebuilt from the message's parts: the text, sender, recipients, date and every attachment are kept, but not the full set of technical headers. If the original can't be deleted (for example, the connection drops), the message says it is now in both mailboxes.

The ⋮ menu holds: Open in new window, Resend (in Sent), Read aloud, Print or save as PDF, Follow up, Pin to top, Save source, Block sender and the rest of the Block menu, and whatever of Full screen, Archive, the flag and Meeting from this message had no room above it. On a tablet a meeting is usually the calendar button beside Forward.

Importance. Mail sent with high importance has a red ! before the sender in the list and Sent with high importance under the sender; low importance has a blue ↓ and Sent with low importance. Mail cached before 2.92.0 gets its mark at the next sync.

Read receipts. When a message asks to be told you read it, a bar over it says so, with Send receipt and Don't send, as Outlook asks. Either answer is kept, so the message does not ask again. Settings → View → Read receipts can send them without asking, or never. Not on mail in Junk, Sent or Drafts. For now only on a Gmail account: whether Microsoft sends a receipt by itself when a message is marked read is not yet known, and answering there too could send two.

Resend. A message in Sent has ⋮ → Resend…, which opens it as a new message, as Outlook's Resend This Message does: the same people, Bcc included, the same subject, text and files, the same importance. Change what you like and send it; the copy in Sent stays where it is.

Unsubscribe. Mail from a mailing list that says how to leave it (newsletters, shops, most marketing) has Unsubscribe beside the sender's address, as in Gmail and new Outlook. Tap it and the app says what it will do before it does it:

  • Where the list allows it, MyEmail tells the list there and then, and that is all.
  • Where the list asks for an email, MyEmail sends it, from the account the message came to; it lands in Sent like any other.
  • Where the list has only a web page, the page opens in your browser to finish there.

Afterwards the link says Unsubscribed on that list's mail. Lists can take a few days to stop. It is not offered on mail in Junk, where unsubscribing tells a spammer the address is read (delete it, or leave it in Junk), nor on mail you sent.

On the tablet, deleting or moving the open message opens the next one in the list, and the list stays where it was; with nothing below, the one above opens. It is shown but not marked read until you choose it.

If a message cannot be loaded, with no signal say, the pane says so at once, with Try again. Opening the message again asks again too. The message on screen and the last three you read are kept in memory, so going back to one is instant; older ones come back from the phone's cache.

An email address that is a link in the message opens a new message here, from the account the message came to, with any subject and text the link carries.

Under the sender, who the message went to is folded to one line: as many names as fit, then how many more (To: Michael Reznik, Gilad Fishman +7 · CC 1). Details opens the full list, every name with its address, nothing cut off; Hide details, on the same line Details was, folds it again. A long list — a company-wide mail to forty people — scrolls in a box of its own, no more than a third of the screen tall, so the message is still there below it. Each message opens folded.

Tap a person — the sender's name, picture or address, or anyone in the Details list — and a card opens with their name and address:

  • Add to contacts opens your phone's new-contact screen with the name and address filled in. Pick the account it goes in (your Google account, say) and tap Save; you come back to the message.
  • Open contact takes its place when they are already in your contacts, and the card says In your contacts (with the name they are filed under, if it differs). This needs the contacts permission the app asks for at the To field; without it the card always offers Add.
  • New email writes to them from the account the message came to.
  • Next and Last, where you have meetings with them, name the next meeting and the last, a year either way of every calendar; tap one for it on the calendar. All meetings with them searches the calendar for them.
  • Copy address puts their address on the clipboard.

Full screen

The ⛶ button (or F11) gives the message the whole display, with the Android bars hidden — worth it for a newsletter laid out for a wide page. A bar with the subject shows briefly and comes back on a tap. Esc, F11 or Back leaves.

Read Aloud

⋮ → Read aloud (on the tablet also Read aloud in the ribbon, or Ctrl+Alt+Space) reads the open message out in the phone's own voice: the subject, then the text, a paragraph at a time. Hebrew is read in a Hebrew voice and English in an English one, each paragraph by the letters it is written in. A web address is said as "link" rather than spelled out.

A bar over the message has ⏮ back a paragraph, ⏸ pause (and ▶ to go on from the start of that paragraph), ⏭ forward a paragraph, where it has got to (3 of 12), the speed (0.75× to 2×) and ✕ to stop. Opening another message, or leaving this one, stops it; so does Stop reading in the menu, or the same key again.

It needs no signal: the voice is Android's. If a message is in a language the phone has no voice for, those paragraphs are skipped and the bar says so, with Voice settings: there, choose Google's speech engine, then Install voice data and the language. Hebrew is listed as Hebrew (Israel).

Summary and suggested replies

On a phone with Google's on-device AI (the Pixel 9 Pro; the Tab S9+ has none), a long message in English shows Summarise above it: a few lines saying what it is about, made on the phone, with nothing sent anywhere. The first time, the phone fetches the AI's model, which takes a minute.

Under an English message from someone else, up to three short replies are offered (Sounds good, Thanks!); a tap starts a reply with those words in, to send as they are or add to. They come from Google's Smart Reply on the phone, on the Tab S9+ too.

Google's models read English only: a Hebrew message has neither.

Pictures

Pictures are not fetched until you say so, because fetching one tells the sender you read the message, when, and roughly where you are.

  • Show images loads them this once.
  • The ⋮ beside it offers Always show from sender or Always show from everyone at domain — the second is the one for shops, which send from a different address every time.
  • Settings → View → Senders you trust lists what you have allowed, with a way to take any of it back.
  • Settings → View → Load pictures automatically turns blocking off entirely.

Pictures that came inside the message itself — a screenshot pasted into it, the logo in a signature — are always shown. They are part of what arrived, so showing them tells the sender nothing. The same pictures are in the quote when you reply or forward, and go out with your message; a forward does not list them again as files.

A message laid out for a fixed width (most newsletters, and some signatures) is scaled down to fit a phone, and shown at its own size on a tablet's wider pane rather than blown up to fill it.

In the dark theme a message is dark too, the colours its sender chose included: a white background goes dark, black text goes light, and a coloured banner keeps its colour, a little darker. Pictures are shown as they are. Settings → View → Theme picks Light, Dark, or System default, which follows Android.

Attachments

Chips under the header, under a line saying how many there are and what they weigh. Tap that line to fold them away, and again to bring them back; the choice holds for the next message too. With many, the chips take at most a quarter of the screen and scroll inside it, so the message is still there below them. Tap a chip to open it. A file is downloaded when you tap it, not when the message opens. If the list of attachments cannot be read, the bar says so, with Try again. Long-press picks it up so you can drag it into another app in split screen. Its menu (⋮) has Open with…, to pick the app this once, save, copy, share, and Default app…, which says which app opens that kind of file. Android does not let one app change another's default, so to change it: tap Open settings there, tap Clear default preferences, open the file again, choose the app and tap Always.

With two files or more, Save all at the end of that line puts every one of them in a folder you pick, with one choice: Android's folder picker opens where you left it last time, the files are fetched as needed, and each goes in under its own name (a name already there gets a number rather than replacing what is there). The bar says when they are all in, or which ones did not make it.

Pictures the message itself shows — a signature's logo, a pasted screenshot — are not listed as chips as well. If one of them cannot be fetched, its chip comes back so it can still be opened.

Opening one offers the apps that handle that kind of file, and goes straight to your usual one where you have set a default. The file's name decides that, not what the sender called it: plenty of systems label every attachment as an anonymous lump of data, and a PDF marked that way used to be offered to anything at all.

An email attached to the message (one dragged into it in Outlook, or forwarded as an attachment) shows with an envelope and opens right here as an email: who it was from and to, its own pictures and files, and its text. A file in it opens, saves and shares like any other, and an email inside that one opens the same way.

A file opened in a version before 2.89.0 is downloaded again the first time you open it now. On Gmail that replaces a copy that would not open.

Printing

⋮ → Print or save as PDF, or Ctrl+P. Android's print sheet opens, and "Save as PDF" is one of the printers in it. The page gets a header block — subject, from, to, date — then the message as it was, pictures pasted into it included. Ctrl+P prints exactly what the menu does, a trusted sender's pictures too, and says Could not print if it fails.

Meeting invitations

An invitation shows as a card under the header: what, when, where, who asked. Accept, Tentative or Decline answers the organiser — through the Outlook calendar for a Microsoft account, and by the standard calendar reply for Gmail. A meeting set in another time zone shows at the right hour for yours. Declining one meeting of a series declines that one only. If a Microsoft invitation cannot be fetched for the moment (a weak signal, Microsoft busy), the message shows without its card, and the card comes the next time you open it.

Once answered, the invitation goes to Deleted Items (Trash on Gmail), as Outlook does, and the meeting stays on your calendar with your answer. The bar says so, with Undo. Settings → Calendar → Delete invitations once answered keeps them in the Inbox instead.

Clashes. Where the meeting asked for overlaps something already on any of your calendars, the card says so under its time, Clashes with Weekly sync, 14:00–15:00, and draws that part of the day with the new meeting outlined over it. Meetings shown as free, declined or all day are not clashes.

⋯ beside the three answers has more ways to answer, as Outlook has them:

  • Answer with a note…: choose Accept, Tentative or Decline and write a line for the organiser, which goes with your answer. On a Microsoft account the same box has Tell the organiser: switch it off and your calendar has the answer but nobody is told (Outlook's Do not send a response), so the note is greyed. Over mail, on Gmail, an answer only counts once it reaches the organiser, so the switch is not there.
  • Propose a new time…, on a Microsoft account: pick the day, the start and the end, Tentative or Decline, and a note. The organiser gets your answer with the time beside it; moving the meeting is theirs to decide. If they switched proposals off for that meeting, the app says Outlook refused it.

Each time you open meeting mail, the card checks the account's own calendar (Outlook, or Google Calendar for a Gmail account signed in with Google) and says where the meeting stands:

  • On your calendar at this time. The calendar has it as the invitation says. An updated invitation (Invitation, updated) is moved on your calendar by Outlook itself; this line is how you know it was.
  • Your calendar has it at … The meeting has moved since this invitation was sent; the calendar's time is the one that counts.
  • Cancelled since, and still on your calendar. The answers give way to Remove from calendar.
  • Nothing, when the meeting is not on the calendar. Add to calendar then hands it to your calendar app, where you pick which calendar it lands in. It is not offered when the account's calendar has it already, nor when the invitation names a time zone the phone cannot work out.

A meeting cancelled shows a red Cancelled card. While the meeting is still on your calendar, Remove from calendar takes it off, as Outlook's button of the same name does; nobody is told, since the organiser already knows. For one meeting of a series, only that meeting is removed. Once it is gone the card says Not on your calendar. A Gmail account with an app password has no calendar the app can reach, and the card says to remove it in your calendar app instead.

A new time proposed arrives when you organised a meeting and someone asks to move it ("New Time Proposed" in Outlook). The card says who proposed it and how they answered, then the Current time beside the Proposed one:

  • Accept proposal asks first, then moves the meeting on your calendar to the proposed time. Everyone invited is sent the new time, the way Outlook's Send Update does.
  • Decline proposal sends the person who proposed it a short email saying the meeting stays at its current time. The meeting is not changed.

Neither is offered when the time proposed is the time the meeting already has, or when your calendar has moved it there already. A proposal for one meeting of a series moves that meeting only.

An answer to a meeting you organised (Accepted, Tentative, Declined) shows who answered and how, with nothing to do.

The calendar button beside Forward on the tablet, or ⋮ → Meeting from this message on the phone, opens a New meeting filled in from it (see Writing mail) — the subject as the title, everyone on the message as the attendees, the text as the notes — for the mail that says "let's meet Thursday" without a real invitation, as Outlook's Reply with Meeting does.

4. Writing mail

✏️ on the phone, New email in the ribbon, or Ctrl+N.

  • To, Cc, Bcc suggest people as you type. The people you write to come first, the ones you wrote to lately before the ones you wrote to long ago; then your contacts; then everyone else who has written to you. No-reply addresses are left out. Tap a suggestion to fill it in. The list appears once you start typing, and a tap anywhere else closes it. Typing matches the start of a name or any word in it, the start of an address or any part of it before the @, and the company part after it: "hadco" finds everyone at hadco.com. Someone already in the field is not suggested again.
  • Contact groups are suggested by their name, first, with a group icon and how many people are in it; choosing one puts everyone in it into the field. Make them in Settings → View → Contact groups: New group, a name, and the people, typed as you would type recipients, with suggestions. They are kept on this device and in the settings backup, not in an account's address book.
  • Forget a suggestion: long-press (or right-click) a name the mail history suggests, a typo you once wrote to say, and it stops being suggested; Undo on the bar brings it back. Writing to that address again brings it back too, as in Outlook. A name from your contacts or an account's address book is that book's, and stays.
  • Your phone's contacts are suggested too. The first time, Android asks for permission to read them; refuse and the suggestions still come from your mail. Settings → View → Writing can ask again.
  • Each account's own address book online is searched too, a moment after you stop typing: Microsoft's people and your organisation's directory for a Microsoft account, your Google contacts and "other contacts" (everyone Gmail saved when you replied) for a Gmail account. Each account allows this once: Settings → View → Writing → Allow beside it, then sign in. A work account's organisation may have to approve it first; Allow sends them the request.
  • From is a menu when you have more than one account. Changing it puts that account's signature in place of the one in the body, or takes it out if that account has none (or is set not to sign replies).
  • Cc is always there; Bcc appears when you tap it.
  • Tab moves between the places you write in: From (with more than one account), To, Cc, Bcc once it is showing, Subject, the message itself, and round again. Shift+Tab goes back. It never stops on a button. In a field the cursor goes after what is already there; in the message, back where it was. With suggestions showing, Tab takes the highlighted one (the first, if you have not moved) and goes on. The keyboard's Next, and Enter in a field, go the same way.
  • One cursor: tap in the message, with a finger, the S Pen or the keyboard cover's touchpad, and the cursor leaves the field above; what the keyboard types goes where the cursor is. The arrow keys move it about the message.
  • A reply opens with the cursor in the message, on the line above the quote. A new message or a forward opens in To.
  • The body is a proper editor, and on a reply the quoted original can be edited too. In the dark theme the quote is dark like the rest; it still goes out in the colours it came in.
  • The bar under the message has what Outlook's Format Text has: bold, italic, underline, strikethrough; font colour and highlight; size (small, normal, large, huge); bullets, numbers, indent and alignment; line spacing; a link; a picture; the Signature menu; and remove formatting. It slides sideways on a narrow screen.
  • A link: select the words and tap 🔗, then type the address (hadco.com is enough; an email address becomes a mail link). With nothing selected, the words to show can be typed too. With the cursor in a link, 🔗 offers to change its address or take the link off.
  • A picture in the text: 🖼 puts one where the cursor is, from your pictures or taken with the camera. It is made a sensible size first (1600 pixels on its longer side, the right way up) and goes inside the message, as Outlook sends a picture, not as an attachment.
  • @mentions: type @ and the start of a name, and the people To would suggest show in a row over the bar. Tap one: the name goes in as @Name, a link to their address, and they are added to To if they are not on the message already, as in Outlook.
  • Enter starts a new line with no gap under the one before, as in Outlook and Gmail; press it twice for a blank line. A reply opens with a line to write on, then a blank line, your signature, another blank line, and the quote. It arrives spaced as you see it.
  • ↕ Line spacing on the bar under the message: Single, 1.5 lines or Double. With text selected it spaces those lines; with nothing selected, everything you have written. The signature and the quote are left as they are.
  • Hebrew (or Arabic) reads from the right as you type it: each line takes the direction of its first letter, so a Hebrew line sits on the right and an English one on the left in the same message, and it goes out that way to Gmail and Outlook. The Subject does the same, as do a meeting's title, place and notes. The quoted original keeps the layout its sender gave it.
  • 📎 attaches a file, 📋 pastes one from the clipboard, and you can drop a file onto the message from another app in split screen.
  • ➤ sends. Ctrl+Enter does too. If the server turns an address down, nothing is sent and the message names it, so you can fix it and send again. While it is sending, Back does nothing; if the send then fails, the window says so.
  • ⋮ at the top right has High importance and Low importance, as Outlook's Tags have them, and Request a read receipt, which asks the reader's mail app to say when it is opened (many apps ask the reader first, and some never send one). What is set shows under the subject. A saved draft keeps them.
  • MailTips, from a Microsoft account: a moment after the recipients change, a line under them says what Exchange knows about them, as Outlook's MailTips do: someone with an automatic reply on (with its first words), someone outside your organisation, a group of 25 people or more, a mailbox that is full or does not take mail from you.
  • Insert free times in ⋮, for a Microsoft account or a Gmail account signed in with Google, writes your calendar's free times into the message for the other person to pick from, as Outlook's Share availability does. Choose the first day, how many working days, between which hours, the shortest gap worth offering, and your work week: Monday to Friday at first, and the days you pick are kept for next time (and for Next free time on New meeting). Each day gets a line, such as Monday 26 October: 09:00–11:00, 14:00–17:00, in your clock's style, with your time zone named above them. Time already gone today is left out.
  • From another app: tapping an email address in another app or on a web page offers MyEmail, and a new message opens to it. An app that shares to MyEmail with people to write to (Calendar's Email guests, an app's Send feedback) fills To, Cc and Bcc, each address once.
  • Reply goes to the sender, or to the address they asked replies to go to, such as a support desk's ticket address behind a no-reply sender. Replying to something you sent goes to the people you sent it to.

Before it goes

Two questions, as Outlook asks them, each with its own switch in Settings → View → Sending:

  • No subject: "This message has no subject. Send it anyway?" Keep writing puts the cursor in Subject.
  • Attachment reminder: when what you wrote says something is attached ("attached", "attachment", "enclosed", or in Hebrew מצורף, מצורפת, צירפתי, מצ"ב) and nothing is. Attach a file opens the file picker, Send anyway sends. The quote of what you are answering and your signature are not read, so a forwarded "see attached" does not count.

Undo Send. After Send the window closes at once and the message waits 5 seconds, with Sending… Undo on the bar; Undo opens it again just as it was. Settings → View → Undo Send makes it 10 seconds, or Off. Put the app away while a message waits and it goes at once. A message written in a window of its own goes at once too. If it cannot be sent, the bar says so, with Open to get it back.

Drafts

Backing out of a message you have written in offers Save draft, Discard or Keep writing; one you have not touched just closes. Saved drafts go to the server, so they are in Outlook and on the web as well. Tap one in Drafts to carry on, attachments and all; if a file cannot be brought back, the screen says so rather than losing it quietly. A draft that cannot be loaded, offline say, is not opened at all, so its first line cannot end up replacing the whole of it.

If the draft's text is on the phone but its saved copy cannot be fetched, offline say, it opens with the Bcc line showing and a note: any Bcc, and any file, are not there to bring back. Saving or sending it then makes a new copy, and the old one stays in Drafts with its files and Bcc, for you to delete when you are done with it.

A Microsoft draft with large files, such as a forward with a big PDF, saves: the message goes up first and each file after it. One whose own text is over about 3 MB, almost always from pasted pictures, cannot, and the screen says to attach the pictures instead.

If you leave the app while writing, to pick a file or to look something up, a copy goes into Drafts in case Android closes the app meanwhile. It is removed again when you send, save or discard, even if it is still going up at the time; Save draft waits for it, so Drafts holds one copy. Putting the app away (Home, or another app) saves the message to Drafts and closes it; see Coming back to the app.

Proofread and rewrite

On a phone with Google's on-device AI, the ✨ button on the bar under the message offers Proofread, Shorter, Friendlier, More formal, Longer and Rephrase. It works on the words selected, or with nothing selected on everything you have written (not the signature or the message you are answering). The answer shows first: Use this puts it in place of the words, Cancel leaves them. The AI takes about 150 words at a time, so select a part of a longer message, and it writes English only.

Signatures

Each account can have as many signatures as you like, each with a name (Full, Short, Hebrew…). Settings → Signatures → Add a signature, or Edit on one, opens the same editor the message uses, with a box for the name. Paste one from Outlook and it keeps its shape; a logo hosted on a web server is fetched once when you save and kept inside the signature, so it still appears if that server later disappears. When you send, the logo goes along as a picture inside the message, which Gmail and Outlook show.

Under each account, New messages and Replies and forwards say which signature each starts with, or None, as in Outlook. While writing, the Signature button on the bar under the message puts another of the account's signatures in place of the one there, or No signature. A signature set up before 2.93.0 is the account's first, used as it was.

If your organisation adds a signature on its own mail server — CodeTwo and the like — it is added after sending and does not show here. Leave this empty in that case.

Automatic replies

Out of office. Settings → Automatic replies lists the accounts and says what each is set to: Off, On, On until Fri 6 Nov, 18:00. Tap one, switch on Send automatic replies, write the message and Save. The server sends the replies, so they go out with the phone off, and Outlook or Gmail on the web shows the same setting.

  • Only during a time period sets when they start and stop; outside it nothing is sent, and you need not remember to switch them off.
  • On a Microsoft account the message goes to people in your organisation. Reply to people outside my organisation decides whether anyone outside gets one (everyone, or Only my contacts), and A different message for them gives them their own words.
  • On Gmail there is a Subject (empty for "Re:" and theirs) and Only reply to people in my contacts. Gmail answers each person at most once every four days while it is on; Outlook once.

The first time, an account may say Not allowed yet: Allow signs it in again asking for its settings, and nothing cached is lost. A work account's organisation may have to approve this first; the sign-in sends them the request. A Gmail account on an app password signs in with Google here instead.

New meeting

The small calendar button above ✏️ on the phone, New meeting in the ribbon, or Ctrl+Shift+M. Choose the account first, then the title, the people, when and where, and Send.

The invitation goes out from that account's own calendar — Outlook for a Microsoft account, Google Calendar for a Gmail account signed in with Google — and the replies collect on the event there, as they would had you made it in Outlook. A Gmail account set up with an app password has no calendar the app can reach, so its meeting is handed to the phone's calendar app instead, people included.

A work account may first have to allow the app its calendar. The screen offers the sign-in that asks; where only your organisation's administrator can allow it, Microsoft's page offers to send them the request, and once they approve, Send works.

Who is free: beside All day, a button says whether the people are free at the meeting's time: Everyone free, Dana busy, 2 busy, No one busy when someone's calendar cannot be seen, or Who is free while it checks. Tap it for each person's day, eight to eight, their busy times as blocks with the meeting outlined over them, as Outlook's Scheduling Assistant shows it:

  • Tap a time on a line to move the meeting there, to the half hour; ‹ and › move it a day.
  • Next free time moves it to the first time after it that everyone shown is free, on a day of your work week (chosen in Insert free times, Monday to Friday until then), between 8:00 and 18:00, over the next two weeks. The meeting keeps its length.

From a Microsoft account everyone in your organisation can be seen, and people outside it show as Not shown. From a Gmail account only your own calendar can be seen: Google asks a further permission to show anyone else's, which the app does not have. It is not there for an all-day meeting, nor for an account set up with an app password.

Online: for an account whose calendar can hold one, the screen has an Online switch named for where the meeting is held: Teams meeting on a Microsoft account, Google Meet on a Gmail account signed in with Google. Switch it on and the invitation goes out with a link to join; the message at the bottom says so. A Microsoft account with a Gmail account signed in with Google beside it has a choice, in a menu next to the switch: Teams meeting, or Google Meet, whose link the Gmail account makes and the Outlook invitation carries (on Google you are the meeting's host, as that account). Choosing from the menu turns the switch on. The first time, the Gmail account may have to allow the app Google Meet: the screen says so and offers the sign-in with Google that asks. The switch is not there for an account set up with an app password, whose calendar the app cannot reach, nor for a Microsoft account that has not yet allowed the app its calendar; allow it and the switch is there the next time you open New meeting.

The link is made as soon as the switch goes on, and what the invitation will say about joining appears under the notes, as Outlook shows it: the Teams block (its Join the meeting now line, Meeting ID and passcode), or the Meet link, with the dial-in number where your Google account has one. The lines cannot be tapped there; Copy link beside them copies the link. The block is shown rather than written in: Microsoft drops the Teams meeting from an invitation whose block was changed, and Google adds its own block to every invitation. Your notes go above it. With the keyboard up on the phone, the block steps aside for the notes.

For Teams, and for Meet on the Gmail account, the meeting sits on that account's calendar (Outlook, or Google Calendar) with nobody invited while you write, titled New meeting until it has a title, shown as free and with no reminder. Send gives it its details, marks you busy, turns its reminder on and invites everyone. Switch it off, change From, or leave without sending, and it is deleted for good without anyone being told. Should the app close with the screen open, the next start deletes it. Should the one shown have gone meanwhile (deleted from Outlook, say), Send makes a new one, and its closing message says the link is new.

If Send fails, with no connection say, tapping it again sends the same meeting: it is never made twice, and nobody is invited twice. Change the meeting before trying again and it reaches the calendar as it now stands; if the first Send had in fact gone through, everyone on it is told of the change.

Once you have picked a date or time, turned on All day or changed From, the screen stays when you switch to another app, to check your calendar say, and Back asks before discarding it.

The calendar button beside Forward (tablet), or ⋮ → Meeting from this message (phone), opens this screen filled in from a message: the subject as the title, the sender and everyone it went to or was copied to as the attendees (never you), the text as the notes, the message's account as From.

Calendar. An account with more than one calendar that takes meetings shows a Calendar box under the account: the meeting goes on the one picked. On a calendar other than the main one, a Teams or Meet link is made as the meeting is sent, rather than ahead.

Repeat, reminder, show as, private, time zone. The sliders button at the top of New meeting opens the rest:

  • Repeat: every day, every working day (your work week, as Insert free times has it), every week or every two weeks on the days you tick (the first meeting's own day always among them), every month on the date or on the same weekday of the month (the fourth Tuesday, or the last), or every year. Ends never, on a day, or after a number of times.
  • Reminder: the calendar's own, none, at the start, or 5, 15 or 30 minutes, an hour or a day before.
  • Show as: busy, free, tentative or out of office. Google Calendar keeps only busy or free.
  • Private: others who can see your calendar see only that the time is taken.
  • Time zone: set the meeting on another zone's clock, so a 10:00 New York call is New York's 10:00 wherever you are. The times on the screen are then that zone's, with yours under them.

What you choose there shows as one line under Location; tap it to change it. Editing a meeting offers the reminder, show as and private too; its repeat and its zone stay as they are.

Type it in a line. The ✨ button at the top asks for the meeting as you would say it, Lunch with Dana Thursday 1pm at Café Noir, and fills in the title, the day and time and, after at, the place. A day without a time is a whole day; from 2pm to 3:30pm sets the end. It is read on the phone, in English.

Calendar

Calendar at the foot of the folder list, in the ribbon, or Ctrl+2, as in Outlook. It shows the meetings of every account whose calendar MyEmail can read: Microsoft accounts, and Gmail signed in with Google. What it last read is kept on the device, so it opens at once and with no signal, and each calendar is asked again behind what is shown; a thin bar runs under the view buttons while it is.

  • Agenda lists the days with something on, from today: scroll down for the days ahead and up for the days before, a month more each time you near the end.
  • Day is the hours of one day, meetings side by side where they overlap; tap an empty half hour to start a new meeting then.
  • Week shows three days, the work week or all seven: choose with ⋮ → Week shows, or in Settings → Calendar. Until you choose, it is the whole week on a tablet and three days on a phone. Tap a day's name to open that day.
  • Month is the month as a grid. On a tablet each day lists its meetings and a tap opens the day. On a phone each day has a dot for each of its first three meetings, the day you tap is listed under the month, and a second tap opens it.
  • Swipe left and right to go on and back a day, a week or a month at a time; ‹ › do the same. Tap the month's name at the top to pick any date from a small month, with a dot on the days that have something on. Today comes back.
  • Pinch Day or Week to make the hours taller or shorter; the height you leave is kept. Day and Week open an hour before now, or on another day at the start of your working day, and the hours outside it are shaded.
  • The filter button, Calendars shown, chooses which calendars are shown, and ⋮ → Refresh reads them all again. + is a new meeting.
  • Search (the magnifier) finds a meeting by its title, a person or a place, a year back and a year ahead, in every calendar: those to come first, soonest first, then Before today. Tap one for its sheet.
  • Tap a meeting for when and where, who is invited and how they answered, Join for a Teams or Meet meeting, and Open in Outlook (or Google Calendar).

Every calendar. Beside each account's main calendar, MyEmail shows its others: the calendars made beside it in Outlook, and in Google those on your calendar list, holidays and birthdays among them (one switched off in Google Calendar stays off). Each shows in its own colour. Calendars shown lists them under their account, each switched on or off. A Gmail account signed in before 3.4.0 shows Allow there instead: sign in again to let MyEmail list its other calendars. A calendar the account only reads, holidays, birthdays or one shared to look at, offers nothing on a meeting's sheet to answer or change.

Colours. A meeting in an Outlook category is drawn in the category's colour, and one given a colour in Google Calendar in that colour, with the account's colour down its edge. Outlook's category colours need the mailbox's settings allowed, as Automatic replies do; until then such a meeting keeps its calendar's colour.

The next meeting, over the mail. From a quarter of an hour before a meeting until it ends, a slim bar over the mail list says so: Weekly sync in 12 min, with Join when it is held online. Tap it for the meeting's sheet; swipe it away and it stays away for that meeting, until the next.

My Day (tablet). The My Day button in the bar over the list, beside Hide folders, puts today's meetings where the folders are: the next meeting's Join at the top, a tap on a meeting for its sheet, and a tap on the date for the calendar. ✕, or the same button again, brings the folders back.

Meeting reminders. MyEmail reminds you before each meeting, at that meeting's own reminder time and on the dot, as Follow Up's reminders are, with a calendar for its icon: its title, when and where, and the time left to its start counting down. Join opens a Teams or Meet meeting. Running late offers 5, 10 or 15 min late (or type a number) and sends the sheet's one-line message. Snooze reminds you again in five minutes, or as it begins if that is sooner. A tap opens the meeting, and the reminder goes by itself once the meeting is over. A meeting with no reminder of its own gets none.

Settings → Calendar → Reminders switches them by account. They start on for a Microsoft account and off for a Google one, since Google Calendar on the phone reminds you of those already; a Microsoft account shown in the phone's calendar starts off too, for the same reason.

Morning agenda. On the days of your work week (as Insert free times has it), at 7:30 unless you choose another time, one notification: 3 meetings today and The first at 09:30: Stand-up, with the day's meetings when you open it out. A day with nothing on stays quiet. Tap it for the calendar. Settings → Calendar → Morning agenda moves it, or turns it off.

MyEmail reads the calendars for the reminders, the agenda and the calendar widget (see Home screen widgets) when it checks for mail and when it is opened, at most every quarter of an hour, and at once after you change a meeting in it.

What a meeting's sheet does. Everything below works on the meeting's own calendar, so Outlook and Google Calendar show it too.

  • Accept, Maybe or Decline a meeting you were invited to, and the organiser is told. Hold one down to add a note, or to answer without telling them. ⋮ → Propose a new time offers another time, on a Microsoft account. For one meeting of a series, it asks whether you mean that one or every one.
  • Edit, on a meeting of yours, opens it as New meeting does, filled in; Save sends the change to everyone on it. For a repeating meeting it asks first: this one, or every meeting in the series. Every one keeps its days, and only the time and the length change. A meeting held online keeps its link.
  • Drag a meeting of yours in Day or Week: hold it, then move it to another time or day. Hold it by its foot to make it longer or shorter. With people on it, it asks first, since they are sent the new time.
  • ⋮ → Cancel meeting, on one of yours with people on it, sends them the cancellation, with a note on a Microsoft account. ⋮ → Delete, on one with nobody else on it, takes it off at once, with Undo. ⋮ → Decline and remove, on someone else's, tells the organiser you declined.
  • ⋮ → Email everyone writes to everyone on it, with its title as the subject. On a meeting of yours the sheet counts the answers, such as 3 accepted · 1 declined · 2 not answered, and Email the … who have not answered writes to them alone.
  • Running late, from an hour before a meeting until it ends, sends a one-line message, I'm running about 10 minutes late: to the organiser, or to everyone on it when it is yours.
  • ⋮ → Invite people, on a meeting of yours, invites the people you add; on a Microsoft account only they are sent anything. ⋮ → Forward, on someone else's Microsoft meeting, sends it on and tells the organiser. Google Calendar has no forward.
  • ⋮ → Duplicate opens New meeting with everything filled in but the day.
  • Mail about this meeting, under the people, lists the messages with its title in the subject from the people on it, the invitation and the answers among them, newest first, searched in the meeting's account; tap one to read it.

Meetings you declined. Google keeps a meeting you said no to on your calendar; Outlook takes it off. MyEmail leaves declined meetings out. ⋮ → Show declined meetings, or the same switch in Settings → Calendar, shows them faint and struck through instead.

With no signal, or a calendar that does not answer, MyEmail shows what it last read, with the account's problem above it, and As read at … when that was more than a few minutes ago.

Calendars from links. Settings → Calendar → Add from a link takes an .ics or webcal:// link (a school's terms, a team's fixtures), and Public holidays picks a country's, as Google publishes them. MyEmail reads each every few hours and keeps it on the device, so it shows with no signal, read only, in its own colour, in Calendars shown, on the calendar widget and in the morning agenda. They are in the backup. The bin beside one takes it off.

Settings → Calendar also sets your Working day, from and to, what Week shows, and a Second time zone, whose hours Day and Week show beside your own. A meeting set in another zone than yours says so on its sheet: Set in New York time: 10:00–11:00.

Dates in mail. A day or a time in a message, Friday at 3pm, is dotted under; tap it for New meeting at that time, with the message's subject and people in it. Only days from today on are marked, the message is read on the phone in English, and Settings → Calendar → Find dates in mail turns it off. The first message opened fetches the small model it reads with.

A calendar that is not allowed yet shows Not allowed yet with Allow, which signs that account in again asking for its calendar; a work account's organisation may have to approve it first.

In the phone's calendar. Settings → Calendar puts a Microsoft account's calendar into Samsung's or Google's own calendar app, as Outlook for Android does: switch the account on and allow the calendar permission. Its meetings then show there with their reminders and on the calendar's widgets, from a month back to a year ahead, read only: change them in Outlook, or answer them in MyEmail. MyEmail brings them up to date when it checks for mail, at most every half hour. Switching it off takes that calendar out of the phone's calendar again. A Gmail account's calendar is there already, through Google.

In its own window (tablet)

Open in new window on the compose screen moves what you are writing into a window of its own. Settings → View → Writing → Write in a new window makes every new message start that way.

5. Sorting and finding

Sort

⋮ — on the phone in the top bar, on the tablet beside the folder name:

  • Date (newest first) — the default
  • Date (oldest first)
  • Sender
  • To
  • Subject
  • Size (largest first)
  • Attachments
  • Flag
  • Importance
  • Account

Sender, To and Subject run A to Z. Subject ignores "Re:" and "Fwd:", so a reply files with the message it answers. The others group the list under bars, as Outlook's Arrange By does: by size from Enormous (over 5 MB) down to Tiny (under 10 KB), With attachments and Without, Flagged and Not flagged, High, Normal and Low importance, or each account by name (worth it in All inboxes). A bar closes and opens with a tap, as the date bars do. The same menu holds Conversations and the row density (Compact, Cozy, Comfortable), and a way through to all view settings.

Search

Tap 🔍 above the list (or Search in the ribbon, or Ctrl+F) and type. It searches subject, sender and body on the server, not only what is on the device, so a folder of thousands is fully covered. The ✕ in the box ends the search and puts the box away.

  • Under the box, All / From / To / Subject / Body / Attachment says which part of the message the words are matched against; All is subject, sender and body together, To is whom it went to (Outlook's Sent To), Attachment is the names of the files on a message, and the choice holds until you change it.
  • A second row of filters narrows the results: Unread, Flagged, Has attachments, Important (marked high importance), This week (since the start of your work week) and Large (over 1 MB). Each tap narrows what was found without asking the server again; closing the search clears them.
  • Recent searches show under the empty box when it opens: tap one to search for it again, or Clear. A search goes there when you press Search on the keyboard or close the box.
  • Save this search (the bookmark in the box) keeps the words, the field, the filters and how far it looked under Saved searches in the folder tree, Outlook's Search Folders. Tap one to run it again, from the server, as it is now; long-press it to rename or delete it. Saved searches are in the settings backup.
  • The scope chooser appears in a real folder: this folder, this account, or everywhere.
  • Results say which folder each hit is in.
  • Long-press a hit to start ticking, then Select all results in the bar, and delete, move, flag or forward as attachment the lot.
  • Results follow whatever sort you have chosen.
  • On Gmail, this account and everywhere (which is what All inboxes searches) also look in All Mail, so mail archived on the web or the phone with no label is found. Spam and Trash are left out. Each message shows once, even with labels on it or when it is Starred or Important: its Inbox copy if it has one, then the copy under a label, and the All Mail copy only when it is nowhere else. Outlook's Archive is searched like any other folder.
  • An account that cannot be reached, or needs signing in again, leaves the other accounts' results in place. When none can be reached, it says Search failed. at once, with Try again.
  • Opening an unread result marks it read in the results too. Moving or deleting a result says so at once, with Undo.
  • The ⋮ menu is still there while searching, and what it does to a hit from another folder happens to that message.

6. Tidying up

Answering from the notification

A new-mail notification carries three buttons: Reply, Reply all and Delete. None of them opens the app.

Reply and Reply all open a box in the notification itself. Type, send, and the reply goes with the original quoted under it and your signature on it, exactly as if you had written it in the app. Delete moves the message to Trash. In every case the notification disappears, and with it the account's summary row if that was its last message, which is how you know it worked.

If a reply cannot be sent, it is saved in Drafts and a notification says so. With no signal at all it waits, and goes once there is one; after a day without one it gives up and says so. If the message you answered has been moved or deleted in the meantime, your reply is kept in Drafts as a new message. If the connection drops while a reply is being sent, MyEmail cannot tell whether it went, so it does not send it again: a notification says to check Sent, and shows what you wrote. What you typed is never thrown away: whenever a reply can be neither sent nor saved, the notification that says so shows what you wrote.

An invitation's notification has Accept, Decline and Reply instead. The answer goes as the invitation's card in the message sends it, to the organiser through the account it came to, and the invitation goes to Deleted Items (or is marked read, where Settings → Calendar keeps answered invitations). With no signal it waits, as a reply does. A meeting's reminder has buttons of its own: see Calendar.

Undo

Anything moved or deleted says so along the bottom, with Undo beside it. Tap it and the messages go back where they were. It works however they left — a swipe, the menu, the ribbon, the keyboard, or dragged onto a folder — and for a whole conversation at once.

Undo is offered whenever it can be honoured. It is not offered for a message deleted out of Trash, or moved out of Trash into another mailbox, because no original is left to put back. The bar goes after a few seconds whether you use it or not; it still works if the message it came from has closed.

Marking several read or flagged goes on past one that fails, and the bar says how many could not be changed.

Recover deleted items

On a Microsoft account, emptying Deleted Items (or deleting something from it) is not the end: Exchange keeps that mail out of sight for a few weeks, two unless the company chose otherwise, and Outlook's Recover Deleted Items brings it back. So does MyEmail: Recover at the right of the bar over Deleted Items, or long-press Deleted → Recover deleted items.

The list shows that mail newest first, who it was from, the subject and when it was deleted; scroll for more, or search it. Tick what you want and tap Restore: it goes back to the Inbox, under its own date, as Outlook on the web puts back mail whose folder it cannot tell. A Gmail account has no such thing; its Trash keeps deleted mail in sight for 30 days.

Archive

Archive is beside Delete above an open message and in the ribbon, in a row's menu, in the bar over ticked messages, and on Backspace, as in Outlook on the PC. A swipe can be set to it too.

On a Microsoft account the message goes to the Archive folder. On Gmail it goes out of the folder it is in and stays in All Mail, as Gmail's own Archive takes the Inbox label off. Undo brings it back either way. Messages from several accounts, ticked in All Inboxes, each go to their own account's archive, with one Undo for all.

Follow up

Outlook's Follow Up: ⋮ → Follow up… above an open message, or in a row's menu. Choose when it is due: Today, Tomorrow, This week (the last day of your work week), Next week, No date, or Choose a day…. The work week is the one chosen in Insert free times, Monday to Friday until then.

  • On a Microsoft account the day is kept on the server: Outlook on the PC shows it, and a day set there shows in Flagged here. On Gmail, which has no dates, the day is kept on this phone.
  • Add reminder… asks for a day and a time, and a notification comes then, even with the app closed; tapping it opens the message. Change reminder and Remove reminder are there once one is set. A reminder flags the message if it was not.
  • Mark complete is done with it: Outlook shows its check mark, and it leaves Flagged. Clear flag, or the flag button, takes the flag off. Both take the day and the reminder with them.

Snooze

⋮ → Snooze… above an open message, in a row's menu, in the ⋮ of the bar over ticked messages, or on a swipe set to it. Choose Later today (three hours on), Tomorrow, This weekend or Next week (each at 8:00, the weekend and the week by your work week), or Choose a day and time….

The message leaves the list at once, into a Snoozed folder on the server, made the first time; Undo puts it back. At its time it goes back to the folder it came from (or the Inbox, if that folder has gone), unread. With the app closed, the background brings it back; in deep sleep Android may make that a few minutes late, and opening the app brings back anything due. Outlook and Gmail on other devices see it in the Snoozed folder meanwhile. Taken out of Snoozed by hand, it stays where you put it.

Block sender and Not junk

In an open message's ⋮ menu: Block sender moves the message to Junk now, and from then on their new mail goes from the Inbox to Junk as it arrives, on the phone and in the background. Undo takes both back. Unblock sender is there instead for someone blocked.

In Junk, Not junk (beside Delete above the message, and in a row's menu) moves it back to the Inbox and makes the sender never blocked. Never block sender and Never block sender's domain are in the menu too: someone never blocked is not moved even when everyone at their domain is.

Settings → View → Blocked senders lists both, for taking an entry off or typing one in: an address, or a domain such as example.com for everyone at it. The lists are the app's; Exchange's and Gmail's own junk filters are left as they are, and mail already in the Inbox stays there.

Check for threats

For a message that looks wrong: ⋮ → Check for threats… opens a sheet with a verdict at the top (No sign of a threat, Be careful with this one or This looks dangerous) and what it is based on, under five headings:

  • What the mail server found: whether the sender's domain vouches for it (SPF, DKIM and DMARC), and Microsoft's own verdict where it has one: phishing, malware, pretending to be someone, spam.
  • The sender: a name showing another address, replies that go to another domain, a domain made to look like one you know (hadc0.com for hadco.com), and whether this is the first mail from the address.
  • Links: words showing one address over a link to another, an address hidden behind an @, a bare internet address, lookalike letters, a shortened link, a link that runs something. Microsoft's Safe Links are taken off first, so it is the real address that is checked; Where its links go lists them.
  • Attachments: a program or script, a name that hides what it is (Invoice.pdf.exe), macros, a web page, an archive.
  • Google Safe Browsing and VirusTotal, once set up: Google says whether it lists any of the links as phishing or malware, and VirusTotal what some 70 antivirus programs make of each attachment. Only the links go to Google, and only a fingerprint of each file to VirusTotal, never the file. The free VirusTotal key checks four files a minute, programs and scripts first.

Everything but the last part happens on the phone. A clean result is not a promise: a new trick is caught by nobody at first.

To set up the two online checks, once on each device (the keys stay on the device, and are not in the backup):

  1. Google: in the Google Cloud console, in the project MyEmail uses, enable Safe Browsing API, then Credentials → Create credentials → API key, and copy it.
  2. In MyEmail: Settings → Threat check → Google Safe Browsing key, paste, Save.
  3. VirusTotal: make a free account at virustotal.com, open your profile menu, API key, and copy it.
  4. In MyEmail: Settings → Threat check → VirusTotal key, paste, Save.

Set up the online checks on the sheet goes to the same screen, and the check runs again with the new key when you come back.

Swipe

Swipe a row left or right. What each direction does is yours to set (Settings → View → Swipe actions): nothing, delete, move, read/unread, flag, archive or snooze. The colour and the word appear as you drag, and on a conversation the word carries the count — "Delete 5" — so you know how much is going before you let go.

Selecting several

Long-press any row to tick it, and keep long-pressing or tapping to add more. A bar appears at the top of the list and offers: select what is on screen (or all results, in a search), read/unread, flag, move, archive and delete, and in its ⋮, snooze and forward as attachment. Esc or ✕ clears the selection.

With a mouse, right-click gives the full menu for one row without ticking anything.

Copying a message

Right-click → Copy, or Ctrl+C, puts the message on the clipboard as an .eml file. Paste it into a message you are writing to attach it, or into a file manager to keep it.

Quick Steps

Settings → Quick Steps builds named chains — say Mark read, then move to Receipts — and they then appear in the ribbon, in a message's right-click menu, and can be applied in one tap.

The actions: mark read or unread, flag or take the flag off, Flag for a day (today, tomorrow, this week, next week or no date, as Follow up), move to a folder, Archive, delete, Forward to someone, Reply, then delete, New message to someone, and Meeting from it. Those that open something open it, and the rest of the chain goes on once it is closed: Forward to Dana, then Archive archives the message once the forward is sent or put away. Archive, a move, a delete and Reply then delete end a chain.

Ctrl+Shift+1 to Ctrl+Shift+9 run the Quick Steps in the order they are listed, as in Outlook; drag them in Settings → Quick Steps to change which number each has.

A step that moves mail files into one account's folder, and mail cannot move between accounts, so that step is only offered on that account's messages. With more than one account, the folder list says whose each folder is.

Rules

Settings → Rules shows each account's rules as its own server runs them: Outlook's Inbox rules on a Microsoft account, Gmail's filters on Gmail. They work on mail as it arrives, with the phone off, and the same rules show in Outlook on the PC and Gmail on the web.

+ makes one: when a message is From someone (addresses or parts of them, with commas) or its Subject has some words, Move it to a folder (or the Archive), Delete it, or Leave it in the Inbox, and Mark it as read besides. With both From and Subject, a message has to match both. A Microsoft rule has a name; Gmail's filters have none and are listed by what they do.

From a message: More → Create rule… starts one with its sender filled in, and This subject puts its subject in with a tap.

A Microsoft rule can be switched off and on; a Gmail filter cannot, only deleted. A rule that does more than these (other conditions, forwarding, exceptions) is listed with Does more than this shows, and is changed in Outlook or Gmail on the web. Rules work on mail from now on, not on what is already in the Inbox. Not allowed yet and Allow are as for automatic replies.

7. Folders

  • Long-press a folder for its menu: new subfolder, rename, move, add to Favourites, hide, mark all as read, empty (Trash and Junk only), recover deleted items (a Microsoft account's Deleted Items), delete. Each entry only appears where the account allows it. On a Microsoft account, Inbox and Archive can have subfolders, and a folder name may contain "/". Mark all as read reaches every unread message however large the folder, and it and Empty show at once in the open list, in All Inboxes and in search results.
  • Drag a folder onto another to nest it, onto a folder's edge to reorder it, or onto the account heading to bring it to the top level. Order is kept on this device — IMAP has no such thing.
  • Long-press an account heading and the tree folds to the account headings alone; drag it onto another heading's top half to put the account before it, bottom half to put it after. The order holds everywhere accounts are listed — the tree, From on a new message or meeting — and across restarts.
  • Favourites sit at the top, in the order you added them; long-press one and drag it above or below another to rearrange them. Let go without moving and you get its menu instead. Hidden folders disappear until you reveal them from the row at the bottom of the tree.
  • The search box at the top of the tree filters the folders themselves. What you typed stays when the phone's drawer is closed and opened again.
  • All Inboxes merges every account's Inbox. Long-press it to put it away; Settings → View → All Inboxes brings it back.
  • Flagged, under it, is everything flagged in every account, whatever folder it is in, soonest due first and those with no day after them, as Outlook's Flagged email. Junk and Deleted Items are left out, and so is anything marked complete. Unflag a message there and it leaves the list.

Two separate things, deliberately.

Settings → Sync — how often MyEmail looks:

Choosing either of the two with a permanent notification also asks Android to let MyEmail run in the background. Say Allow. Without it, Android refuses them whenever it restarts MyEmail on its own, and mail is then checked only every 15 minutes until you open the app. Settings → Sync shows a red band with an Allow button while that is missing.

On Android 15 and later, the two with a permanent notification run for about six hours a day unless MyEmail is opened. Opening it starts them again, and Settings → Sync says when Android stopped them. With push on, Gmail says the moment mail arrives. Microsoft accounts cannot (their instant alerts need IMAP, which Hadco's administrator would have to allow), so they are checked every minute, their Inbox only. Every five minutes everything is checked, every account and its folders, in case an alert was missed.

While MyEmail is open it keeps what is on screen current whatever the setting: the list on screen and the folder counts ask the server again every minute, and within seconds of the background sync finding new mail (with "Every 5 minutes" or "Push"). A folder you have left stops asking, and catches up once when you open it again. Nothing is asked while the app is in the background, where the setting above decides, and coming back reads everything once. Pulling the notification shade down and up, a system dialog, or a tap between two apps in split screen is not coming back, and starts no refresh.

Settings → Notifications — whether to announce it: a master switch and a mute per account. A muted account still syncs, so its mail is waiting when you open the app.

Tap an account's row there for more:

  • Tell me about: All new mail, or Only mail from VIPs. VIPs are listed under Settings → Notifications → VIPs; add someone from a message (tap their name, Add to VIPs) or type an address there.
  • Do Not Disturb, as Outlook for Android has it: For 1 hour, Until tomorrow (8:00), Every evening between two hours you choose (18:00 to 08:00 at first), and Weekends, all day on the days off in your work week. End now ends an hour or a night early. Mail still comes in while it is quiet; it is only not announced, then or after.
  • Folders: switch on any folder besides the Inbox, and the background checks it with the Inbox and announces its new mail the same way: a folder a server rule fills, say.

The account's row says what is set: Quiet until 9:41, Quiet evenings, VIPs only.

Each notification shows the app's icon, the dart, in the account's colour, so you can tell which account the mail came to before reading it — and on Android 17 and later so does the row Android draws over a group of them, beside the app's name and the account's. The colour is the one set under Settings → Accounts, and by day it is exactly that colour. At night, when the phone is in dark mode, Android lightens it so it stands out against the dark shade. The sender is in the notification's first line, with the account's name after it. On earlier Android versions the row over a group keeps the app's own icon, and each notification carries the coloured dart on its right.

Tapping a notification opens that message, at once even when MyEmail is already open.

Each account keeps at most eight new-mail notifications in the shade; as more arrive, the oldest are taken down. The mail stays unread in the app. Android stops showing an app's notifications at fifty, which a few days of unread newsletters used to reach, and new mail then went unannounced.

9. Home screen widgets

Drop the MyEmail widget on the home screen. It asks which account, then which folder, then whether to count everything or only unread, and lets you name it and pick a colour.

The first colour on offer is the account's own, from Settings → Accounts, and it is picked unless you choose another. A widget left on it changes when you recolour the account. Pick a different one to tell two widgets of the same account apart. A widget for All inboxes has no account, so it starts orange.

The widget is the size and shape of an app icon: the number top right is what has arrived since you last looked, the number bottom left is what the folder holds. Tapping it opens that folder. With push on, the top number follows each minute's check; the folder's count, for a Microsoft account or a folder other than an Inbox, follows the full check every five minutes.

Settings → Home screen widgets changes any of that afterwards.

The calendar widget, MyEmail's second, lists today's and tomorrow's meetings from every account in the calendar, each with its account's colour down its side, as many as fit: make it taller for more. Tap a meeting to open it in MyEmail, Join to join one of today's held online, and the date for the calendar. It drops each meeting as it ends, and MyEmail brings it up to date when it checks for mail, at most every quarter of an hour.

10. Windows and split screen

Mostly a tablet thing, and it works in DeX.

  • ⋮ → Open in new window on a message, or the ⧉ button while writing.
  • From a full-screen app the new window opens full screen; put the two side by side from Recents ("Open in split screen view"), or drag one in. Already in split screen, the new window takes the other half. In DeX each is simply its own window.
  • Each window is its own copy of MyEmail. They share the mail on the device but not what is selected, which means two messages can be read side by side.
  • In split screen you can drag a message row from one window into the other: it arrives as an .eml file, and dropped onto a folder it is moved there, as a drag in the folder pane is. A folder that cannot take it refuses it (Gmail's Sent Mail, Drafts and All Mail, the Outbox, All inboxes, the folder it is in), and the bar offers Undo.

13. Backup and updates

Backup

Settings → Backup writes a file holding your accounts, the folder tree's shape, favourites, hidden folders, Quick Steps, signatures, swipe actions, sort and the senders you trust. Sign-in details go in only if you tick Include sign-in details, and then they are locked with a passphrase you choose. Restoring the file on a fresh device puts all of that back. Updates

Settings → About → Check for updates looks at the releases MyEmail is published to, downloads the new version and installs it. Android asks once for permission to install from MyEmail. The app also notices a new version on its own and says so on the About row.

14. When something looks wrong

A message looks broken or blank. Some senders build mail that needs pictures to make sense. Tap Show images. If it still looks wrong, ⋮ → Save source writes the message exactly as it arrived, which is the thing to look at.

A message is hard to read in the dark. Usually a picture drawn for a white page, such as a black logo on a see-through background. Settings → View → Theme → Light shows everything as it was sent.

Archive on Gmail. Gmail has no Archive folder: archiving takes the message out of the folder it was in, and it stays in All Mail, which is where to find it again. Archive does nothing in All Mail itself, and says so.

An attachment vanished from a draft. A draft reopened from Drafts brings its attachments back. If one cannot be brought back, the screen names it; attach it again.

Mail arrives late. Check Settings → Sync. "Occasionally" lets Android decide, and overnight it decides slowly. "Every 5 minutes" or "Push" are the ones that are prompt, and both show a permanent notification because Android will not let a background app do that quietly. If a red band there says Android limits MyEmail in the background, tap Allow.

A notification arrived but the message is not in the list. It should appear within seconds; pull down to sync, or press F9, to have it now. Mail that a server-side rule filed outside the Inbox is not what the background pass watches; an open list of that folder finds it within a minute.

Two copies in Sent on Microsoft. There should not be: Graph files the sent message itself and MyEmail adds nothing. If you see two, say so.

The widget shows old numbers. It is redrawn by the background sync, so it is as current as Settings → Sync allows. Opening the app refreshes it.

Not seen on a real device yet. Full screen reading, and dragging a message between two windows in split screen, are both built and covered by tests but have not been tried by hand on the tablet. If either misbehaves, that is where to look first.
